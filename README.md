> End-to-end data science platform · 3,000 orders · 5 zones · 10 analytical modules

## 📊 What's Inside
| Module | Description |
|--------|-------------|
| Overview | Monthly GMV trends, zone revenue, weather impact |
| Cohort Retention | 6-cohort heatmap, retention curves, activation cliff |
| Zone RFM | Champion/High Value/At Risk zone segmentation |
| Operations | Delivery bottleneck, scatter analysis, hourly demand |
| Restaurants | Top 15 leaderboard, Pareto concentration |
| A/B Testing | 3 experiments with p-values, power tables |
| Anomaly Detection | Z-score rolling window, 8 flagged events |
| Dynamic Pricing | Surge multiplier matrix, elasticity by zone |
| ML Models | Random Forest (R²=0.71), Logistic Regression (AUC=0.78) |

## 🔑 Key Results
- **Zone A** identified as Champion segment (AOV $49.50, lowest cancel rate)
- **Surge pricing A/B test:** p=0.023, +$4.80 AOV at <2% conversion loss  
- **Dynamic pricing** projected +$17.8K GMV uplift (+12.5%)
- **Zone congestion** is #1 delivery time predictor (31% feature importance)
- **Jan cohort** achieved 42% M2 retention vs 35% industry benchmark
